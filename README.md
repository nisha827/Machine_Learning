# Machine Learning

A collection of machine-learning experiments and coursework projects.

## Adult Income Classification

The [Adult Income Classification project](Adult_Income_Dataset_Classification_ML_Models/README.md) compares reproducible classification baselines on the UCI Adult dataset. The refreshed implementation preserves numeric and categorical features, keeps preprocessing and resampling inside training pipelines, and evaluates against an untouched stratified test set.

See the project README for setup, methodology, tests, and limitations.
